### 📌 About The Project

This web application was developed as part of an intensive, hands-on training track at the **Kanz Hackathon**—officially recognized by **Guinness World Records** as the largest hackathon globally. The program focused on showcasing how developers can dramatically accelerate end-to-end web prototyping and development by leveraging **modern AI tools**. 

By pairing AI-assisted engineering with standard software design principles—specifically the **Model-View-Controller (MVC)** architectural pattern—the project illustrates how full-stack solutions (catalog browsing, cart interaction, and database persistence) can be conceptualized, structured, and deployed in record time.

[![Guinness World Record](https://img.shields.io/badge/Guinness%20World%20Records-Largest%20Hackathon-FF8C00?style=for-the-badge&logo=target&logoColor=black&labelColor=FFD700)](https://github.com/Hanan71/Bakery_web)

### ⚡ AI-Driven Rapid Development Highlights

* **Accelerated Prototyping:** Utilizing generative AI tools to rapidly scaffold boilerplate code, controllers, and domain models.
* **Streamlined UI/UX Construction:** Fast assembly of responsive storefront views and styling with AI assistance.
* **Automated Data Modeling:** Prompting and refining schema structures, migrations, and seed logic to minimize setup overhead.
* **Rapid Problem Solving:** Leveraging AI-driven debugging to resolve architectural and routing bottlenecks swiftly.

---

### ✨ Key Features

* **Product Catalog & Categorization:** Browse various bakery items and pastries with pricing and descriptions.
* **Order & Cart Flow:** Intuitive user journey to select baked goods and manage order inquiries.
* **Clean Architecture:** Built strictly on the MVC pattern for maintainability and separation of concerns.
* **Database Migrations:** Automated schema generation and persistence using Entity Framework Core.

---

### 🛠️ Tech Stack & Tools

* **AI Assistance:** Generative AI tools & coding assistants for rapid scaffolding and development
* **Backend Framework:** C#, ASP.NET Core MVC
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Database & ORM:** Microsoft SQL Server, Entity Framework Core
* **Version Control:** Git & GitHub

### 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Hanan71/Bakery_web.git](https://github.com/Hanan71/Bakery_web.git)
   cd Bakery_web
   ```

2. **Restore dependencies:**
   ```bash
   dotnet restore
   ```

3. **Apply database migrations:**
   ```bash
   dotnet ef database update
   ```

4. **Run the application:**
   ```bash
   dotnet run
   ```
